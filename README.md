# TokuDataCore [![Downloads](https://img.shields.io/github/downloads/LovekovGaming/TokuDataCore/TokuDataCore.zip?displayAssetName=false)](https://github.com/LovekovGaming/TokuDataCore/releases) [![Discord](https://img.shields.io/discord/355766960207691778)](https://discord.gg/3b37BRX)

This Minecraft data pack serves as a library for other data packs designed for the
TokuCraft family of mods.

It allows data packs to trigger functions when the player transforms or
detransforms, and (in the case of characters with multiple forms) assigns each form slot
a scoreboard with a numeric ID for each form. This allows ranges of forms to be processed
easily and efficiently.

## Prerequisites

- Minecraft 1.21.1, running NeoForge
- A mod in the TokuCraft family. TokuDataCore currently supports [Kamen Rider Craft](https://modrinth.com/mod/kamen-rider-craft), [Super Sentai Craft](https://modrinth.com/mod/super-sentai-craft), [UltraCraft/Ultraman Craft](https://www.curseforge.com/minecraft/mc-mods/ultraman-craft), [Power Rangers Craft](https://modrinth.com/mod/power-rangers-craft), and [TMNTCraft](https://modrinth.com/mod/tmntcraft)

## Installing

### For New Worlds
Install on a new world by clicking the More tab on the Create New World screen, then clicking
the Data Packs button. Then drag and drop the **TokuDataCore** zip file
onto the Minecraft Window. This should make it show up in the Available column. Click the
icon for the pack to move it to the Selected column, then hit Done. The pack will activate
as soon as you create the world.

### For Pre-existing Worlds
Install on a pre-existing world by copying the **TokuDataCore** zip file to
the datapacks folder of the world. If you don't know where this is, click the Edit button
in the Singleplayer Worlds list, then click the Open World Folder button.

Once the pack has been copied, run the `reload` command if you have the world open. The pack
will activate once the reload is complete.
