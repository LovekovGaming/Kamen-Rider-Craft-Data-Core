# Kamen Rider Craft Data Core

This Minecraft data pack provides core functionality for other packs designed for the
[Kamen Rider Craft](https://modrinth.com/mod/kamen-rider-craft) mod.

It detects transformations for Riders with multiple forms, and assigns each form slot a scoreboard
with a numeric ID for each form. This allows ranges of forms to be processed easily and efficiently.
It is compatible with both the release and dev builds of Kamen Rider Craft.

## Prerequisites

- Minecraft 1.21.1, running NeoForge
- The [Kamen Rider Craft](https://modrinth.com/mod/kamen-rider-craft) mod

## Installing

### For New Worlds
Install on a new world by clicking the More tab on the Create New World screen, then clicking
the Data Packs button. Then drag and drop the **Kamen-Rider-Craft-Data-Core** zip file
onto the Minecraft Window. This should make it show up in the Available column. Click the
icon for the pack to move it to the Selected column, then hit Done. The pack will activate
as soon as you create the world.

### For Pre-existing Worlds
Install on a pre-existing world by copying the **Kamen-Rider-Craft-Data-Core** zip file to
the datapacks folder of the world. If you don't know where this is, click the Edit button
in the Singleplayer Worlds list, then click the Open World Folder button.

Once the pack has been copied, run the `reload` command if you have the world open. The pack
will activate once the reload is complete.
